# Arboria

An animated tree that changes with the seasons.

Drag the slider at the bottom to move through spring, summer, autumn and winter. The tree, lighting and effects (petals, fireflies, falling leaves, snow) blend as you go.

## Run

Open `index.html` in a browser. No build step or dependencies.

## Controls

- Slider: scrub through the year
- Season labels: jump to a season
- Auto-cycle: play through the seasons automatically
- Sound: toggle ambient audio
